# PATCH — IDEAL Fazenda Front (Standalone) V1

Este patch cria um frontend **standalone** (Vite + React) com o **mesmo layout/estilo do CRAS** (CSS e componentes do padrão).

## Rodar
```bash
cd frontend
npm install
npm run dev
```

## Telas incluídas
- Início (Modo Produtor / Mês) — KPIs (R$/@), tendência (placeholder), Top 5 custos, resumo, alertas
- WhatsApp — Validações (Pendentes/Ambíguos/etc) + resolução de ambiguidade (mock)
