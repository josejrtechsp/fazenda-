# PATCH IDEAL_FAZENDA FRONT V15N — Tight 30%

Este patch reduz ~30% (fontes/padding) **apenas** no dashboard do produtor, via classe de escopo `faz-dash-tight30`.

## Aplicar
1) Unzip na raiz do projeto IDEAL_FAZENDA.
2) Rodar:
   - `bash tools/apply_front_v15n_tight30.sh`
   - `bash tools/verify_ideal_fazenda_front_v15n.sh`

## Arquivos
- `frontend/src/styles/fazenda_dash_tight30.css`
- `tools/apply_front_v15n_tight30.sh`
- `tools/verify_ideal_fazenda_front_v15n.sh`
